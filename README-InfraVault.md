# خزنة البنية — InfraVault

تطبيق iPhone لإدارة كلمات سر البنية التحتية (Servers, O/S, Hypervisor, VM, Switches, Routers, Firewalls) مع مشاركة عبر واتساب.

📂 المشروع داخل المجلد: [`InfraVault/`](./InfraVault/)

```bash
cd InfraVault
npm install
npx expo start
```

افتح التطبيق على الآيفون عبر Expo Go، أو ابنِ نسخة أصلية عبر Xcode / EAS.

التفاصيل الكاملة في [InfraVault/README.md](./InfraVault/README.md).
